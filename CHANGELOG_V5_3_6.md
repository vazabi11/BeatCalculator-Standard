# SiraCalc V5.3.6 — Unified Copy & History UI
Base: main 3b355d777be2f69e464d69038ff237b0037d18a0 (5.3.5 / 14). Target: 5.3.6 / 15. Application ID remains com.beatoflove.standardcalculator.

- Standard / Scientific: remove duplicated hamburger and title; put consistent 24dp vector Copy and History icons in the result panel with 48dp touch targets, ripple, tooltips and accessibility descriptions. Preserve existing shared history, recall and memory (MC).
- Formula Pro: compact action strip plus existing Setup; COMP retains expression replay and previous history; SD and REG store calculated reports independently, including regression prediction history. Report copy uses the actual calculated report, not the COMP result.
- Financial: Accounting uses existing chronological tape (displayed newest first in History) and retains Tape / Grand Total. Clearing the new History does not reset GT. Other tools, including COST/SELL/MARGIN/MU and all Business/Finance/Investment calculators, copy the current output and store per-tool results after Calculate. Changed form inputs invalidate stale results.
- Currency Convert and Converter: result actions; offline per-tab history, newest first, up to 100 entries. Stable output recorded after 1.2 seconds; immediate Copy also records it. A valid default conversion can be recorded. Consecutive duplicate label/result pairs are ignored. Delayed entries from detached views or from before clearing history are discarded. Exchange Rates, Fuel and Markets are unchanged.
- History UI: dark native dialog, separate result copy, existing recall where available, confirmation before clearing the new history dialogs. New tool logs store result/context locally; they do not restore input controls. No new permissions or network services.
- Existing calculation engines, providers, cache, package ID, global navigation, version naming and publication gate remain unchanged. Update previous structural check for the new Converter copy action and add V5.3.6 structural checks. GitHub Actions builds a DEBUG/testing APK; no automatic merge or publication.

## Verification limitations
Source changes are delivered as an update overlay applied to the exact main SHA by Termux. The complete repository is cloned on the device and a full source archive is generated from the committed tree. Prepared-source anchor checks, new helper syntax and packaging checks are not Android compilation or device QA. GitHub Actions and real-device testing are required. Check APK signing continuity before installing over an existing version. Existing Accounting Tape/Grand Total control retains its original behavior.
