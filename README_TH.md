# Calculator — Sirawit Labs · V5.1.0

ผู้พัฒนา: Sirawit Dh. · © 2026 Sirawit Labs

คู่มืออัปเดต GitHub Web: `GITHUB_WEB_V5_1_TH.md`

โปรเจกต์ Android Native Java, 7 โหมด; หน้าตาใหม่เป็นโค้ดจริงใน MainActivity.java. ใช้ Application ID เดิม `com.beatoflove.standardcalculator` เพื่อรักษาเส้นทางอัปเดต (ลายเซ็น APK ต้องตรงกัน).

ข้อมูลราคา: PTT OR, บางจาก, Rakhagold (ทองไทย), ThaiGoldToday (สำรอง), Gold API (Spot). แสดงเฉพาะราคาอ้างอิงที่ผ่านการตรวจสอบและเก็บแคชล่าสุด. ซ่อน Shell เนื่องจากยังไม่มี API ที่ตรวจสอบสิทธิ์ได้.

สถานะ: ทดสอบ Java แบบ standalone ผ่าน แต่ยังไม่ได้คอมไพล์ Android หรือยืนยันราคา API บนมือถือในรุ่นนี้. การแก้ PTT เป็นการเพิ่มความเข้ากันได้ของตัวอ่าน, ไม่ใช่การรับรองว่า API ต้นทางส่งราคาจริง.
